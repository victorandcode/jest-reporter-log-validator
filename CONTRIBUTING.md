# Contributing

Thank you for wanting to contribute to this project.

## General guidelines

- Use semantic commit messages.
- Keep commits small and focused.
- Update the documentation when behavior changes.
- Run `pnpm check` and `pnpm test` before opening a pull request.

## Setup

```bash
# Install dependencies
pnpm install

# Run tests
pnpm test

# Run formatting and linting
pnpm check
```

Supported runtime versions are Node.js 18.14+ and Jest 26–30. The CI matrix covers the supported
Jest majors.

## Discussions and RFCs

Please create an issue so it can be discussed there.
